# NOCTUNE — 仕様メモ（2026-07-28）

## 確定仕様
- タイトル: NOCTUNE 固定 / アイコン: fork PNG（角丸矩形、ひし形なし）
- UI: 深海ガラス。絵文字禁止。ホームは brand + モード一覧のみ
- 設定: 問題数 5/10/20（共通・既定5）、A4、音名表記、音量
- 音当て: 基準なしの単音識別を廃止し、相対音感の学習モードに変更
  - 音の向き→3音→5音→7音→12音。おまかせは正解で難化、誤答で一段戻し、次回の開始段階を端末保存
  - 3/5/7音は I–IV–V–I の調性文脈→目標音。主音を表示し、実音名を答える
  - 12音はラベル付き基準音→目標音。白鍵のみの時は7音まで
  - 「音の道すじ」は主音／基準音から目標音までを順に再生し、使用時は自力正解に数えない
  - 正解を押すまで次へ進まない。誤答は無効化し、最初のタップのみ記録
  - v5移行時、課題が異なる旧音当てベスト記録はリセット
- 旧既定10問の保存値は v4 移行で5問へ（明示選択20は保持）
- 和音当て: 構成音の音名当て（pitch-set）。和声的 / フリー
- 結果: 全問ログ＋聴き分けインサイト＋行タップ再生
- 操作: 早押し・stopAll・聴くリップル
