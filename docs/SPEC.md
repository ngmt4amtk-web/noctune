# NOCTUNE — 仕様メモ（2026-08-05）

## 確定仕様
- タイトル: NOCTUNE 固定 / アイコン: fork PNG（角丸矩形、ひし形なし）
- UI: 深海ガラス。絵文字禁止。ホームは brand + モード一覧のみ
- 設定: 問題数 5/10/20（共通・既定5）、A4、音名表記、音量
- 音当て: 開放弦を基準にしたバイオリン向け音名練習（絶対音感テストではない）
  - セットアップは `音域` のみ: `7音` / `2オクターブ` / `バイオリン音域`（既定は7音）
  - 出題は自然音のみ。臨時記号・向き判定・段階式・おまかせ・ガイド旋律なし
  - ラウンド内はシャッフル袋。プールを使い切るまで同じMIDIを出さない
  - 第1問のみ G3→D4→A4→E5 の開放弦キャリブレーションのあと、該当開放弦→問題音
  - 以降の問は該当開放弦→問題音のみ。同時発音・ビブラート・正誤のピッチSFXなし
  - 答えは C–D–E–F–G–A–B の7択（表記はグローバルの doremi/abc）。1タップで確定
  - 広い音域でも採点はピッチクラスのみ。誤答時のみ開放弦→問題音を1回再生
  - 弦・指は第1ポジションの単一マップ（境界の開放弦は新しい弦側）。例: C4=G線3指、F4=D線2指
  - v6移行時、課題が異なる旧音当てベスト記録とおまかせ進捗だけリセット
- 旧既定10問の保存値は v4 移行で5問へ（明示選択20は保持）
- 和音当て: 構成音の音名当て（pitch-set）。和声的 / フリー
- 結果: 全問ログ＋聴き分けインサイト＋行タップ再生
- 操作: 早押し・stopAll・聴くリップル

## 限界・正直さ
- トレーニング音はオシレータによる合成音。バイオリンの実録音ではない
- 「相対音感が科学的に最適に身につく」「絶対音感がつく」といった主張はしない
