# NOCTUNE — 仕様メモ（2026-08-05）

## 確定仕様
- タイトル: NOCTUNE 固定 / アイコン: fork PNG（角丸矩形、ひし形なし）
- UI: 深海ガラス。絵文字禁止。ホームは brand + モード一覧のみ
- 設定: 問題数 5/10/20（共通・既定5）、A4、音名表記、音量
- 音当て: 開放弦を基準にしたバイオリン向け音名練習（絶対音感テストではない）
  - セットアップは3項目だけ: `音域` / `使う音・表記` / `毎問の開放弦`
  - 音域: `1オクターブ`（C4–B4）/ `2オクターブ`（C4–B5）/ `バイオリン音域`（G3–B5）。1オクターブ説明に「白鍵なら7音・♯／♭なら12音」と明記
  - 使う音・表記: `白鍵のみ`（自然音・7択）/ `♯系`（全半音・♯表記の3列12択）/ `♭系`（全半音・♭表記の3列12択）
  - 毎問の開放弦: ON なら各問と「もう一度」で該当開放弦→問題音。OFF なら出題と「もう一度」は問題音だけ。誤答確認だけは学習用に開放弦→問題音（設定説明に明記）
  - ラウンド開始時は通常runner UIの前に開放弦カウントイン（G3→D4→A4→E5）。各音開始と同じstepイベントで中央表示が「ソ→レ→ラ→ミ」と変わり、4音のrelease完了後に無音0.48秒の白字「START!」で着地する。音中にSTARTは出さない。HUD・回答・もう一度は出さない。第1問へ4音を再混入しない。進行ドットや説明文は足さない
  - ラウンド内はシャッフル袋。プールを使い切るまで同じMIDIを出さない。補充境界でも直前MIDIを避ける
  - 答えは1タップで確定。時間制限・until-correctなし。広い音域でも採点はピッチクラスのみ
  - 弦・指は `positionsForString` 由来の単一マップ。境界の開放弦 D4/A4/E5 は新しい弦側
  - 音当て専用に厚い正解SFX・連続正解SFX・穏やかな誤答SFX・完了／自己ベスト完了SFXと視覚 reward burst。問題再生前・再生中には鳴らさず、次の問題前に `stopAll`。他3モードのSFX名・回数・完了音は変えない
  - `prefers-reduced-motion` では装飾アニメを抑える（導入cueの順序は残す）
  - 旧v6設定は新項目を既定補完。音当て記録は不必要にリセットしない。v6移行時に課題が異なる旧ベストとおまかせ進捗だけリセット済み
- 旧既定10問の保存値は v4 移行で5問へ（明示選択20は保持）
- 和音当て: 構成音の音名当て（pitch-set）。和声的 / フリー
- 結果: 全問ログ＋聴き分けインサイト＋行タップ再生
- 操作: 早押し・stopAll・聴くリップル
- キャッシュバストトークン: `0805c1`（全モジュール一致）

## 限界・正直さ
- トレーニング音はオシレータによる合成音。バイオリンの実録音ではない
- 「相対音感が科学的に最適に身につく」「絶対音感がつく」といった主張はしない
- 報酬SFXや視覚バーストは知覚できる報酬感・継続意欲を狙う。ドーパミン分泌などの生理作用は測定せず保証しない
